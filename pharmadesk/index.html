Need help?

Common questions

Do I need Laragon to run PharmaDesk?

No. The desktop package includes the PHP and MySQL runtime required by PharmaDesk. Customers do not need to install Laragon separately.

Do I need to install PHP or MySQL myself?

No. The Windows application package includes its required runtime components.

How do I receive future updates?

PharmaDesk has an integrated update system. New official releases are published through the PharmaDesk release channel and the application can check for them.

Can I install PharmaDesk on another computer?

The installer itself is a normal Windows application installer. Product access and any future licensing rules are handled separately by Lishaq Solutions.

Where do I get support?

Contact Lishaq Solutions through WhatsApp or the website contact page for installation, usage, backup, or update assistance.
